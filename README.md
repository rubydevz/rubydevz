# Olá, Prazer! 👋

**`Engenharia da Computação | FullStack | Dados | Cibersegurança`**

Sou uma desenvolvedora de 22 anos, apaixonada por tecnologia e resolução de problemas. Atualmente, estou cursando **Engenharia da Computação** na Uninter e sou formada como **Técnica em Desenvolvimento de Sistemas** pelo Instituto Federal de Brasília (IFB).
